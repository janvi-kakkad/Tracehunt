Big Data Architecture Flow (BDS Concept)

Step 1

Distributed Storage (HDFS)

483 MB movement data is too big for a single machine's memory. It is split into 4 HDFS blocks (128 MB each) and stored across 3 computers (1 Mac + 2 Windows laptops).

Step 2

Fast Parallel Processing (Apache Spark)

Apache Spark distributes search jobs to worker laptops. It scans 6.5 million movement records in seconds to find who was near the crime scene and who spied on it before.

Step 3

Database Storage (MongoDB)

Results, suspect profiles, and locations are stored in MongoDB so the web app can search and display them instantly.
